사람·AI비서를 찾는 일부터 K-Market이 위임하는 판매자·상품 탐색까지, 혼디 안의 모든 검색 요청을 전담하는 유일한 실행 에이전트입니다.

정보를 나열하는 검색창이 아니라 "이 사람이 맞습니까?"를 스스로 판단하고, 확신이 없으면 추측 대신 되묻는 자율 에이전트입니다.

처리 흐름

혼디 생태계 전체의 유일한 검색 실행 에이전트

사람·AI비서 식별은 물론, K-Market 등 다른 서비스가 위임하는 판매자·상품 탐색까지 전담합니다. "검색은 K-Search만 전담한다"는 원칙이 생태계 전체에 적용됩니다.

1
검색 요청 접수
사용자의 직접 검색 또는 다른 서비스로부터의 위임 요청으로 시작됩니다.
2
대상 판단
키워드·유형(주소·직업·닉네임·핸들·GDC 보유 여부·신뢰도 등)을 기준으로 검색 범위를 좁힙니다.
3
결과 제공
모호하면 되묻고, 결과가 없으면 지어내지 않고 솔직하게 안내합니다.
정직한 한계 — 절대 금지 원칙

guid를 지어내지 않고, 확신 없이 단정하지 않습니다

⚠
guid 추측 금지 — 반드시 실제 조회한 결과의 primary_guid만 반환합니다. "아마 이 사람일 것"이라는 추측으로 채우지 않습니다.
⚠
동점 후보 임의 확정 금지 — 동점에 가까운 후보가 둘 이상이면 임의로 하나를 골라 반환하지 않고, 반드시 되묻거나 후보를 제시합니다.
⚠
PDV 비노출 — 이용자의 취향·이력·관계 정보를 검색 대상(제3자)에게 노출하지 않습니다. 공개 프로필(is_public=true) 범위 안에서만 검색합니다.
⚠
미청구 프로필 구분 표시 — 반환하는 guid가 정식 서명 계정(verified)인지 미청구 임시 프로필(provisional)인지 항상 구분해 명시합니다.
⚠
일부 후속 기능 구현 중 — 검색 라우팅의 핵심 기능은 가동 중이나, 미청구 프로필 자동 생성 등 일부 후속 기능은 아직 구현 중입니다.
